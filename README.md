# 인공지능의 개념과 원리 학습 시뮬레이터

고등학교 인공지능 기초 Ⅰ단원 「인공지능의 개념과 원리」(교과서 16~27쪽) 수업용 웹 활동지입니다.

- 활동 10개: 학습 계획, 개념, 특성 카드와 사례 연결, 튜링·역 튜링 테스트 체험, 활용 사례, 자율주행 3단계, 탐색(미로, BFS/DFS 비교), 역량 정리, 선택 활동, 계획 점검
- 형성평가 5문항과 느낀 점 입력
- 학생별 활동 모니터링(진행률, 완료한 활동, 형성평가 점수, 틀린 문제 번호) + 가상 학급 시뮬레이션

## 글 공유 (선택)
기본값은 각 기기 브라우저에만 저장됩니다. 학생끼리 글을 공유하려면 `index.html` 맨 위 주석의 Apps Script를 구글 시트에 배포하고, 웹 앱 주소를 `SHEET_URL`에 넣으세요.
